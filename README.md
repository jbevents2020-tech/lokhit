# Lokhit Newsroom

Modern newsroom platform for creating, editing, approving, and publishing Marathi news.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Gemini AI
- WordPress REST API
- Vercel

## Development

The initial foundation is being built for the Lokhit Newsroom workflow:

Reporter → Draft → Editor Review → Approval → WordPress Publish
